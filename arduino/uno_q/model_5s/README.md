# model_5s/

5-second-window DS-CNN bundle (same architecture, `frames=249`, `win_seconds=5.0`),
generated by `tools/prepare_model.py`. Generated files are git-ignored.

Trained on the 5 s feature dataset (`models/data/urban_safety_5s_features.pt`):

```bash
# rebuild the 5s dataset
cd models && PYTHONPATH=src python -m acoustic_models.urban_safety \
  --win-seconds 5.0 --out-cache data/urban_safety_5s_features.pt

# retrain + export the checkpoint
PYTHONPATH=src python -m acoustic_models.train_classifier --dataset urban_safety \
  --cache data/urban_safety_5s_features.pt --epochs 30 \
  --out artifacts/ds_cnn_urban_safety_5s.pt \
  --export-onnx artifacts/ds_cnn_urban_safety_5s.onnx

# export the runtime bundle here
python arduino/uno_q/tools/prepare_model.py \
  --checkpoint models/artifacts/ds_cnn_urban_safety_5s.pt --out arduino/uno_q/model_5s
```

Held-out (fold 10) metrics: window acc 0.718 / clip acc 0.705 (see the app README
for the full comparison with the 1 s model).
